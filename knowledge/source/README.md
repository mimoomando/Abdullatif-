# `knowledge/source/` — النصوصُ الخام

**ما هذا المجلّد؟** بيتُ **نصوص المدرّب كما نطقها**، لا تلخيصي لها.

```
knowledge/source/     ⬅ النصُّ الخام            (هنا)
knowledge/episodes/   ⬅ توثيقي للدرس + اقتباسات
knowledge/analyses/   ⬅ ما قِيس على البيانات
```

---

## ⛔ ولماذا وُجد

طلب المستخدم (2026-09-25):

> «احفظ نصوص كلّ دروس المدرّب في ملفات داخل `knowledge/source/` —
> ملفّ لكلّ درس… فلا تعود مرتبطة بمحادثة واحدة»

**والطلبُ صائب.** فالمحادثةُ تُضغط وتنتهي، والمستودعُ يبقى. وكلُّ ما
في `episodes/` **توثيقٌ مشتقّ**: يحمل الاقتباسات الحاسمة، ويُسقط
باقي النصّ. فإذا ضاع الأصل، لا يُستخرج منه ما لم أقتبسه يومها.
