## سياسة الدمج

المبدأ الحاكم من المصدر الأصلي:

> كل محتوى جديد يُصنَّف **داخل** هذه الاستراتيجية كتنقيح أو شرط أو مرشّح أو تأكيد أو هدف
> أو قاعدة مخاطرة — لا كاستراتيجية منفصلة.

**عند تعارض السلسلتين:**

1. الأكثر تفصيلًا ورقمية يفوز
2. عند التساوي: الأحدث يفوز
3. عند تعارض جوهري: **يُوقَف ويُعرَض على المستخدم** — لا يُحسم تلقائيًا

كل قاعدة تحتفظ بمرجع مصدرها (السلسلة + رقم الدرس).
