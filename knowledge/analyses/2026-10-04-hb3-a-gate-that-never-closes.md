# HB3 — **بوّابةٌ لا تُغلق في أيّ حال**

**التاريخ:** 2026-10-04 · **كُشفت على شاشة المستخدم**

> ⭐⭐ **وكشفها المستخدمُ لا أنا.** أرسل لقطةً وسأل [هل يسجّل]،
> **والجوابُ كان في سطرين متتاليين منها.**

---

## الدليل — **من الشاشة، لا من القراءة**

```
10-04 23:12   last tick 00:00 (-47 min ago) - feed alive
10-04 23:18   last tick 00:00 (-41 min ago) - feed alive
```

**والتكّةُ ثابتةٌ عند 00:00 والعمرُ يكبر** ⇒ **التغذيةُ واقفةٌ
يقينًا** — وهو عينُ ما تقوله ترويسةُ `mt5_bridge.last_tick_time`:

```
التكّةُ تتقدّم  ⇒  التغذيةُ حيّة
التكّةُ ثابتة   ⇒  لا بياناتٍ تأتي — أيًّا كان السبب
```

**والحكمُ المطبوع `feed alive`.**

---

## ⛔⛔⛔ والعلّةُ في سطرٍ واحد

```python
# runner.evidence — قبل الإصلاح
age = (now - tick).total_seconds() / 60       # now محلّيّ · tick بتوقيت الخادم
verdict = "FEED STOPPED" if age >= 5 else "feed alive"
```

| الطرف | مرجعُه |
|---|---|
| `now` | `datetime.now()` — **ساعةُ الجهاز** |
| `tick` | `bridge.last_tick_time()` — **بتوقيت الخادم** (`_server_time`) |

⇒ **فالفرقُ إزاحةُ الوسيط لا عمرُ التكّة.** وخادمُ المستخدم متقدّم
⇒ **العمرُ سالبٌ دائمًا** ⇒ `age >= 5` **لا تتحقّق في أيّ حال**.

⭐ **والبرهانُ محسوبٌ لا مقدَّر** — وهو مُختبِرٌ قائمٌ الآن:

```python
old_age = (datetime(2026,10,4,23,18) - datetime(2026,10,5,0,0)).total_seconds()/60
assert old_age < 0           # ⬅ −42 دقيقة
```

## ⛔⛔ وأثقلُ ما فيه: **موضعُها**

هذه البوّابةُ **بُنيت لهذا الغرض وحدَه** بعد ليلة 09-21 — حين قال
الإنذارُ [أعد تشغيل البوت] فأُعيد مرّتين **والعطبُ في التغذية**.
وترويستُها تقول إنّها تفصل:

```
last tick 21:58 (97 min ago)   ⬅ تغذيةٌ واقفة: انتظر، لا تعد التشغيل
last tick 23:34 (1 min ago)    ⬅ تغذيةٌ حيّة: العطبُ في الجسر
```

⇒ **وهي الوحيدةُ التي لا تستطيع هذا الفصل.** وصنفُها مسجَّلٌ في
`CLAUDE.md` منذ شهر: **[بندٌ معلَنٌ لا يعمل، ويصمت عند تعطُّله]**.

## ⚠️⚠️ ولم تكشفه الاختباراتُ الأربعة — **ولماذا**

```python
evidence(tick=self.NOW - timedelta(minutes=97), now=self.NOW)
```

⇒ **التكّةُ مبنيّةٌ من `NOW` نفسِها** — أي **بلا إزاحةٍ أصلًا**.
**فجُرّبت الحالةُ التي لا يقع فيها العطبُ وحدَها.**

⭐ **وهو FU3 بعينه** (بُنيت شمعةٌ **لا تتقاطع** مع الوقف ⇒ فمرّ
`minutes_beyond_stop`) — **وثالثُ مرّاتِ الدرس:**

> **يُسأل المُختبِرُ: أبنيتُ الحالةَ التي يقع فيها العطب، أم
> السهلة؟**

⇒ **والمُختبِرُ الجديد يبني الإزاحةَ عمدًا** ويثبّت أنّ الختمَ
**بعد** الآنِ المحلّيّ:

```python
self.assertGreater(frozen, self.NOW, "المُختبِرُ نفسُه بلا إزاحة")
```

## ⇒ والعلاج — **لا تُطرح ساعتان مختلفتان أصلًا**

```python
held = (now - since).total_seconds() / 60     # ⬅ الطرفان محلّيّان
verdict = "FEED STOPPED" if held >= STALE_TICK_MINUTES else "feed alive"
```

و`since` لحظةٌ **محلّيّة**: متى رُئيت **هذه القيمةُ** أوّلَ مرّة —
يحفظها `Heartbeat` في كلّ تمريرة. ⇒ **فالحكمُ من تقدُّم التكّة**،
وهو ما تقوله الترويسةُ بنصِّها، **ولا إزاحةَ تدخل الحساب.**

⚠️ **والعتبةُ 5 دقائق هي هي منذ 09-21** — **والذي تغيّر كيف تُقاس.**
(القاعدة ①: لا رقمَ جديد.)

### ⛔ ولماذا **لا** يُصلَح بإضافة الإزاحة

`measure_server_offset` **تقيس الإزاحةَ من التكّة نفسِها**:

```
الإزاحة = ختمُ التكّة − الساعةُ الحقيقيّة
```

⇒ **فتغذيةٌ واقفةٌ تعطي إزاحةً زائفةً بقدر توقّفها بالضبط** —
فيخرج العمرُ صفرًا **ويبدو العطبُ سليمًا**. **وهو MB1 بعينه**
(الحارسُ يمسك العطلةَ ولا يمسك الانقطاع).

⇒ **وصار الآنُ المحلّيُّ يُطبع مع ختم التكّة** فتصير الإزاحةُ
**مرئيّةً** بدل أن تختبئ في طرحٍ خاطئ — وهو عينُ ما صُحّح في
`self_check` يوم 09-30 بعد MB1.


⭐ **وستّةُ مُختبِرين جُدد**، منها: تكّةٌ تتقدّم مع إزاحةٍ كبيرة تبقى
`feed alive` · والعدُّ يبدأ من جديدٍ حين تتحرّك التكّة · **وصفٌّ
مكتوبٌ لا يُصفّر مراقبةَ التكّة** (فالفرعُ الناجحُ يرجع فورًا، ولو
تُتبّعت التكّةُ بعده لكان **العطبُ نفسُه في موضعٍ ثانٍ**).
