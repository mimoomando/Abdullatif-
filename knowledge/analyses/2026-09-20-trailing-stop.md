# نقلُ الوقف مع الأهداف — بُني، وقِيس، **وربح**

**قِيس:** 2026-09-20 · على 09-14…15 · من السجلّ (M15 كاملٌ فيه)

---

## القاعدة

```
بلغ الهدف ١  ⇒  الوقف إلى الدخول + 1$      ⬅ منصوص
بلغ الهدف ٢  ⇒  الوقف إلى الهدف ١           ⬅ المستخدم
بلغ الهدف ٣  ⇒  الوقف إلى الهدف ٢  … وهكذا  ⬅ المستخدم
```

**المنصوص** (الأوردر بلوك · ج3):

> «بس ضرب الهدف الأوّل، **بدك تأمّن**… بترفع الستوب لوز **لفوق دخولك
> بدولار**، مشان إذا صار انعكاس قوي انت **بتطلع صفر**»

⚠️ **والدولارُ ليس نقطةَ تعادل — هو فوقها.** وعلّتُه في قوله نفسِه:
«بتطلع **صفر**». فالتعادل الحرفيّ يخرجك بخسارة السبريد، والدولار
يغطّيها.

🔶 **وما بعد الخطوة الأولى قرار المستخدم** (2026-09-20)، ثم قال
«ابنها مثل ما قال المدرّب» ⇒ فالأولى بالدولار. **والمدرّب لم ينطق
إلّا بالأولى** — فالسلّم لا يُنسب إليه.

---

## ⭐⭐⭐ القياس — وثلاثةُ أعمدةٍ لا عمودان

وأوّلُ حسابٍ عملتُه قارن **«اخرج عند الهدف الأوّل»** بـ**«اجرِ
بتأمين»**، فأعطى ‎+7.38$. **وكان مضلّلًا**: فيه تغييران معًا — الجري،
والتأمين. فلا يُعرف أيُّهما فعل.

فأُضيف عمودٌ ثالث يعزلهما:

```
                  ① اخرج عند TP1   ② اجرِ بلا تأمين   ③ اجرِ بالتأمين
────────────────────────────────────────────────────────────────────
09-14 20:45           −17.67$          −17.67$          −17.67$
09-15 17:15           +21.30$          +28.68$          +28.68$
09-15 18:45           +14.42$          −14.35$          +14.42$
────────────────────────────────────────────────────────────────────
الحصيلة               +18.05$           −3.34$          +25.43$
```

| | |
|---|---|
| **② − ①** الجري وحده | **−21.39$** ⬅ الجري بلا تأمين **يخسر** |
| **③ − ②** التأمين وحده | **+28.77$** ⬅ التأمين هو الذي أنقذه |
| **③ − ①** الاثنان معًا | **+7.38$** |

### وما تقوله الصفقة الثالثة وحدها

```
09-15 18:45   اخرج عند الأوّل  +14.42$
              اجرِ بلا تأمين   −14.35$     ⬅ عادت وضربت وقفها الأصليّ
              اجرِ بالتأمين    +14.42$     ⬅ خرجت عند الهدف الأوّل محميّة
```

⇒ **وهذا بالضبط ما وصفه**: «مشان إذا صار انعكاس قوي انت بتطلع صفر».
وقع الانعكاس القويّ، وأنقذه التأمين.

⭐ **ويتّسق مع جملته الأخرى في الدرس نفسه**: «**ما تنطر دائمًا آخر
هدف — السوق أزكى منّي ومنك**». فالجري وحده خسارة، والجري المحميّ ربح.
القاعدتان واحدة.

## ⚠️ حدودٌ تُذكر مع الرقم

| | |
|---|---|
| **ثلاثة إعدادات** | عيّنةٌ تكشف عطبًا ولا تثبّت قاعدة |
| **دقّة ربع ساعة** | ومسارُ السعر داخل الشمعة مجهول |
| **التشاؤم مقصود** | شمعةٌ بلغت هدفًا ووقفًا منقولًا تُقرأ **عند الوقف** |

🔶 **وقيمةُ الرقم في اتّساقه مع نصّه، لا في حجمه.** ثلاثُ صفقاتٍ لا
تُثبت؛ لكنّ الآليّة التي تنبّأ بها المدرّب وقعت كما وصفها.
