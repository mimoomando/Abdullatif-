> الأربعةُ الجديدة سلّمًا يتحرّك فعلًا؟** — **والجواب: نعم.**


## ⭐⭐⭐ وصفّان اختلفا — **وفي جهتين متضادّتين**

```
09-15 17:15  buy   tp1 +21.30$   ⇐   tp2 +28.68$     +7.38$  ⬅ عائدُ الحمل
09-23 06:30  sell  tp1  +6.73$   ⇐   tp1  +1.00$     −5.73$  ⬅ كلفةُ التأمين
```

**والسبعةُ الباقية متطابقةٌ إلى السنت.**

### ⭐⭐⭐ وأوّلُ مرّةٍ تُقاس فيها كلفةُ التأمين في هذا المشروع

كان مكتوبًا بعد قياس 10-02:

> [كلفةُ التأمين = **صفر** ⬅ لأنّ التأمين **لم يُشغَّل أصلًا**]

**وقد شُغّل الآن** — وصفُّ 09-23 هو برهانُه. **ومن الكود لا من
التخمين** (`replay.walk_managed`):

```python
hit_stop = (bar.l <= stop) if buy else (bar.h >= stop)
if hit_stop:
    name = "stop" if reached == 0 else f"tp{reached}"
    return out(name, bar.time, stop)      # ⬅ الخروجُ عند الوقف
```

⇒ **واسمُ `tp1` هنا لا يعني بلوغَ الهدف**، بل: **بُلغ هدفٌ واحد
⇒ فتحرّك الوقف ⇒ ثمّ ضُرب الوقفُ المنقول**. والحصيلةُ **من سعر
الخروج** — وهو `stop` لا `target`.

✅ **والرقمُ نفسُه يثبته**: الخروجُ ‎+1.00$‎ **هو `BREAK_EVEN_PLUS`
بعينه**، وسندُه منصوص:

```
«بترفع الستوب لوز لفوق دخولك بدولار»     ⇒  BREAK_EVEN_PLUS = 1.00
```

⇒ **فالصفقةُ بلغت هدفَها الأوّل (‎+6.73$‎)، فنُقل الوقفُ إلى الدخول
+ دولار، ثمّ ارتدّ السعرُ فضربه** ⇒ خرجت بـ‎+1.00$‎ بدل ‎+6.73$‎.

## ⇒ والميزانُ صار كاملًا لأوّل مرّة

```
عائدُ الحمل     (09-15)   +7.38$   ⬅ هو هو، إلى السنت
كلفةُ التأمين   (09-23)   −5.73$   ⬅ وأوّلُ مرّةٍ تُقاس
──────────────────────────────────────
الصافي                    +1.65$
```

⭐⭐ **وهذا ما تَعِد به ترويسةُ `walk_managed` بنصِّها**: [الفرق بين
`walk` و`walk_managed` على المسار نفسِه هو **كلفةُ التأمين أو عائدُه،
بالدولار**]. وكان مكتوبًا 10-02 أنّه [**لا هذا ولا ذاك**] — **والآن
هو الاثنان معًا.**

### ⛔⛔ والتأمينُ **لم يُنقذ خسارةً واحدة**

الثلاثةُ الخاسرة خرجت باسم `stop` في العمودين، **وبخسارةٍ تساوي
مخاطرتَها بالضبط**:

```
−7.35 = مخاطرة 7.35   ·   −8.77 = مخاطرة 8.77   ·   −6.29 = مخاطرة 6.29
```

**و`walk_managed` تكتب `stop` فقط حين `reached == 0`** ⇒ **فلم يُبلَغ
فيها هدفٌ واحد** ⇒ **الوقفُ في مكانه الأصليّ**.

⇒ **فعلى تسعةِ إعدادات: السلّمُ تحرّك مرّةً واحدة، وكلّفت. ولم يحمِ
دولارًا واحدًا من خسارة.** ⚠️ **وذلك ليس عطبًا في السلّم** — فهو
مبنيٌّ ليؤمّن **بعد** الهدف الأوّل («بس ضرب الهدف الأوّل، بدك
تأمّن»)، والخاسرُ لا يبلغه.

| **تسعةُ إعدادات** | والفرقُ من **صفقتين** |

⇒ **ولم يُقلب `grade(walker=walk)`.**
