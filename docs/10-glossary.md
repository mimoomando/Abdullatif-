# 10. مسرد المصطلحات

## أساسيات السوق

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| العرض | Ask / Offer | أقل سعر يقبله البائعون — تشتري به |
| الطلب | Bid | أعلى سعر يقبله المشترون — تبيع به |
| السبريد | Spread | الفرق بين العرض والطلب؛ تكلفة فورية |
| السيولة | Liquidity | سهولة الدخول والخروج دون تحريك السعر |
| التقلّب | Volatility | مقدار تحرك السعر خلال فترة |
| دفتر الأوامر | Order Book | قائمة أوامر البيع والشراء المعلّقة |
| العمق | Depth | حجم الأوامر المتاحة عند كل مستوى سعري |
| الحجم | Volume | كمية الوحدات المتداولة في فترة |
| الفجوة | Gap | فرق سعري بين إغلاق وافتتاح دون تداول بينهما |
| الانزلاق | Slippage | فرق بين السعر المتوقع والمنفَّذ |

## المراكز والأوامر

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| مركز شراء | Long | تربح إذا صعد السعر |
| مركز بيع | Short | تربح إذا هبط السعر؛ خسارته نظريًا غير محدودة |
| أمر سوق | Market Order | تنفيذ فوري بأفضل سعر متاح |
| أمر محدد | Limit Order | تنفيذ عند سعر محدد أو أفضل |
| وقف الخسارة | Stop Loss | أمر يغلق المركز لتحديد الخسارة |
| جني الأرباح | Take Profit | أمر يغلق المركز عند الهدف |
| الوقف المتحرك | Trailing Stop | وقف يتبع السعر لصالحك ولا يتراجع |
| أحدهما يلغي الآخر | OCO | وقف وهدف معًا؛ تنفيذ أحدهما يلغي الثاني |
| سارٍ حتى الإلغاء | GTC | أمر يبقى فعّالًا حتى تلغيه |
| نقطة التعادل | Break-even | نقل الوقف لسعر الدخول لإلغاء المخاطرة |

## الرافعة والهامش

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| الرافعة المالية | Leverage | التحكم بمركز أكبر من رصيدك عبر الاقتراض |
| الهامش | Margin | المبلغ المحجوز كضمان للمركز |
| الهامش الحر | Free Margin | الرصيد المتاح لفتح مراكز جديدة |
| مستوى الهامش | Margin Level | حقوق الملكية ÷ الهامش المستخدم، بالنسبة المئوية |
| مطالبة التغطية | Margin Call | تحذير بضرورة إيداع مزيد من المال |
| التصفية | Stop Out | إغلاق إجباري للمراكز عند نفاد الهامش |
| حقوق الملكية | Equity | الرصيد + أرباح/خسائر المراكز المفتوحة |

## القياس والأداء

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| وحدة المخاطرة | R | المبلغ المخاطر به في الصفقة كوحدة قياس |
| العائد/المخاطرة | R:R | الربح المحتمل مقابل الخسارة المحتملة |
| القيمة المتوقعة | Expectancy | متوسط الربح المتوقع لكل صفقة |
| عامل الربح | Profit Factor | إجمالي الأرباح ÷ إجمالي الخسائر |
| التراجع | Drawdown | الهبوط من قمة الحساب إلى قاعه |
| نسبة شارب | Sharpe Ratio | العائد المعدّل بالتقلّب |
| نسبة النجاح | Win Rate | نسبة الصفقات الرابحة — **مؤشر مضلل بمفرده** |

## أدوات ومنتجات

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| عقد آجل | Futures | التزام بالشراء/البيع مستقبلًا بسعر محدد |
| خيار | Option | حق لا التزام بالشراء/البيع بسعر محدد |
| خيار شراء / بيع | Call / Put | حق الشراء / حق البيع |
| العلاوة | Premium | سعر شراء الخيار |
| عقد فروقات | CFD | تبادل فرق السعر دون تملّك الأصل |
| صندوق مؤشر | ETF | سلة أصول تُتداول كسهم واحد |
| اللوت | Lot | وحدة الحجم القياسية |
| النقطة | Pip | أصغر وحدة حركة قياسية في الفوركس |
| السواب | Swap | رسوم/عائد تبييت المركز عبر الليل |
| التدوير | Rollover | نقل المركز من عقد منتهٍ إلى التالي |

## التحليل الفني

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| الدعم | Support | مستوى يظهر عنده شراء يوقف الهبوط |
| المقاومة | Resistance | مستوى يظهر عنده بيع يوقف الصعود |
| الاتجاه | Trend | ميل عام للحركة صعودًا أو هبوطًا |
| الاختراق | Breakout | كسر مستوى مهم |
| الاختراق الكاذب | Fakeout | كسر يرتد فورًا عكس اتجاهه |
| الارتداد | Pullback | تصحيح مؤقت ضد الاتجاه |
| الدايفرجنس | Divergence | تباعد بين حركة السعر وحركة المؤشر |
| RSI | Relative Strength Index | مؤشر زخم من 0 إلى 100 |
| MACD | — | مؤشر زخم قائم على متوسطين أسّيين |
| ATR | Average True Range | مقياس رقمي للتقلّب |
| المتوسط المتحرك | Moving Average | متوسط السعر عبر عدد من الفترات |
| بولينجر باندز | Bollinger Bands | نطاقات تقلّب حول متوسط متحرك |
| الشمعة | Candlestick | تمثيل للافتتاح والإغلاق والأعلى والأدنى |
| الدوجي | Doji | شمعة بجسم شبه معدوم تدل على التردد |

## التحليل الأساسي والاقتصاد

| المصطلح | الإنجليزية | المعنى |
|---------|-------------|---------|
| مضاعف الربحية | P/E | السعر ÷ ربحية السهم |
| القيمة الدفترية | Book Value | صافي الأصول بعد الالتزامات |
| العائد على حقوق الملكية | ROE | كفاءة استخدام رأس المال |
| التوزيعات | Dividends | أرباح نقدية تُوزَّع على المساهمين |
| رأس المال السوقي | Market Cap | السعر × عدد الأسهم |
| التضخم | Inflation | ارتفاع المستوى العام للأسعار |
| الناتج المحلي الإجمالي | GDP | إجمالي النشاط الاقتصادي |
| منحنى العائد | Yield Curve | العلاقة بين العوائد والآجال |
| شهية المخاطرة | Risk-on / Risk-off | ميل السوق نحو الأصول الخطرة أو الآمنة |
| الملاذ الآمن | Safe Haven | أصل يُطلب وقت الأزمات (ذهب، سندات سيادية) |

## أنماط التداول

| المصطلح | الإنجليزية | المدة |
|---------|-------------|--------|
| سكالبينج | Scalping | ثوانٍ إلى دقائق |
| تداول يومي | Day Trading | داخل الجلسة، بلا تبييت |
| تداول تأرجحي | Swing Trading | أيام إلى أسابيع |
| تداول موقعي | Position Trading | أشهر إلى سنوات |
| تتبّع الاتجاه | Trend Following | ركوب الاتجاه حتى انتهائه |
| الارتداد للمتوسط | Mean Reversion | المراهنة على عودة السعر لمتوسطه |
| التحوّط | Hedging | مركز معاكس لتقليل مخاطر مركز قائم |
| المراجحة | Arbitrage | استغلال فروق سعرية بين أسواق |

## مصطلحات دارجة

| المصطلح | المعنى |
|---------|---------|
| **السوق الصاعد (Bull)** | سوق في اتجاه صعودي ممتد |
| **السوق الهابط (Bear)** | سوق في اتجاه هبوطي ممتد |
| **FOMO** | الخوف من تفويت الفرصة؛ سبب رئيسي للدخول المتأخر |
| **اصطياد الأوقاف** | حركة سريعة تلمس تجمعات أوامر الوقف ثم ترتد |
| **اليد القوية / الضعيفة** | من يحتمل التقلّب مقابل من يخرج عند أول ضغط |
| **التصحيح** | هبوط بنحو 10% من القمة |
| **السوق الهابط الرسمي** | هبوط بنحو 20% أو أكثر |
