# أسبوع الملاحظة — خطوة بخطوة

الهدف: تشغيل البوت أسبوعًا على جهازك، ثم إرسال سجلّه إليّ **لأستنتج
الأرقام من الواقع لا من التخمين**.

⛔ **قبل كل شيء:** البوت **لن يفتح صفقة** — ولا حتى على الديمو. يقرأ
ويحكم ويسجّل فقط. لا خطر على مال، ولا على حساب.

---

## ١. تأكّد أن بايثون مثبَّت

افتح **Command Prompt** (اكتب `cmd` في قائمة ابدأ) واكتب:

```
python --version
```

- ظهر رقم مثل `Python 3.11.5` ⇒ تمام، انتقل للخطوة ٢.
- ظهر خطأ ⇒ نزّله من [python.org](https://www.python.org/downloads/)
  و**ضع علامة على `Add python.exe to PATH`** أثناء التثبيت. هذه
  العلامة أكثر ما يُنسى، وبدونها لن يعمل شيء.

---

## ٢. أنزل المشروع

```
cd %USERPROFILE%\Desktop
git clone https://github.com/mimoomando/Abdullatif-
cd Abdullatif-
git checkout claude/trading-explanation-9heszl
```

**ليس عندك git؟** افتح رابط المستودع في المتصفّح ⇒ زر **Code** الأخضر
⇒ **Download ZIP** ⇒ فُكّه على سطح المكتب. واحرص أن تختار الفرع
`claude/trading-explanation-9heszl` من القائمة أعلى الصفحة **قبل**
التنزيل، وإلا نزّلت نسخةً قديمة.

## ٣. ثبّت مكتبة MT5

```
pip install -r requirements.txt
```

مكتبة واحدة فقط (`MetaTrader5`). بقية البوت مكتبة بايثون القياسية.

---

## ٤. جهّز الطرفية

1. افتح **MetaTrader 5** وسجّل الدخول على **حسابك التجريبي**.
2. اضغط `Ctrl+U` لفتح **Symbols**، وابحث عن الذهب.
3. تأكّد أنه ظاهر في نافذة **Market Watch** — إن لم يكن، أضفه.
4. **انسخ اسمه بالضبط** كما يظهر. قد يكون `XAUUSD` أو `XAUUSD.m`
   أو `XAUUSDm` أو `GOLD`.

⚠️ الاسم الخطأ يعطي «الرمز غير موجود» — وهذا أرحم من تحليل خاطئ صامت.

**واترك الطرفية مفتوحة.** البوت يقرأ منها؛ إن أُغلقت توقّف.

---

## ٥. املأ ملفّ الإعدادات

```
copy config.local.example.py config.local.py
notepad config.local.py
```

غيّر سطرين لا أكثر:

```python
MT5_PATH = r"C:\Program Files\MetaTrader 5\terminal64.exe"
SYMBOL = "XAUUSD.m"
```

- **`MT5_PATH`**: مسار `terminal64.exe`. لتجده: اضغط بزر الفأرة
  الأيمن على أيقونة MT5 ⇒ **Properties** ⇒ انسخ ما في خانة
  **Target**. ولو كانت طرفية وسيطك باسمه فالمسار يحمل اسمه.
- **`SYMBOL`**: الاسم الذي نسخته في الخطوة ٤.

**اترك `MT5_LOGIN` و`MT5_PASSWORD` فارغين** ما دامت الطرفية مسجَّلة
الدخول أصلًا — وهو الأفضل: كلمة السرّ لا تُكتب في ملفّ أبدًا.

🔒 `config.local.py` ممنوع في `.gitignore`، فلن يُرفع إلى المستودع.

## ٦. الفحص الذاتي — لا تتخطَّ هذه

```
python -m bot.mt5_bridge
```

اقرأ ما يطبعه، وابحث عن ثلاثة أشياء:

| ما تراه | ماذا يعني |
|---|---|
| `🕐 إزاحة خادم الوسيط: UTC+3` | **أرسله لي** — بدونه تنزاح كل قاعدة زمنية |
| `💵 السبريد الحيّ: 0.28` | **أرسله لي** — أرضية كل وقف |
| `✅ يطابق ما قرّرته (دولار لكل دولار)` | حجم العقد صحيح |

⚠️ **إن ظهر بدل الأخير:**

```
⚠️ لا يطابق ما قرّرته (توقّعتَ 1.00$)
```

**قف وأرسل لي السطر.** يعني أن عقد وسيطك مصغَّر، وكل حساب مخاطرة
مبنيّ على رقم خطأ. لا تُشغّل الأسبوع قبل تصحيحه.

## ٧. جرّب تمريرة واحدة

```
python -m bot.runner
```

يطبع مثل:

```
⛔ وضع الورق — لا أوامر تُرسل. تسجيل فقط.
📁 C:\Users\...\Abdullatif-\runs
✅ سُجّل 3 قرارًا (الإجمالي 3)
```

افتح مجلّد `runs` وتأكّد أن الملفّات ظهرت. إن نجحت، انتقل.

---

## ٨. شغّله للأسبوع

```
python -m bot.runner --watch --every 60
```

يفحص كل دقيقة ويسجّل ما جدّ. **اترك النافذة مفتوحة.**

**ثلاثة أشياء تُفسد الأسبوع — احذرها:**

1. **لا تغلق نافذة الـ Command Prompt.** صغّرها فقط.
2. **امنع الجهاز من النوم**: Settings ⇒ System ⇒ Power ⇒ اجعل
   Sleep على **Never**.
3. **اترك MT5 مفتوحًا** طوال المدة.

انقطعت الكهرباء أو أُغلق الجهاز؟ **لا بأس.** أعد تشغيل الأمر نفسه —
السجل يُلحَق ولا يُكتب من جديد، والقرارات القديمة لا تتكرّر.

لإيقافه: `Ctrl+C`.

## ٩. ماذا يتجمّع عندك

```
runs\
├── decisions.jsonl      كل قرار — للآلة
├── trades\              ⭐ ملفّ لكل صفقة — لك أنت
│   ├── 000-index.txt        الفهرس: ابدأ منه
│   └── 20260905-1845_H4_accepted.txt
├── charts\              الشموع عارية (افتحها بالمتصفّح)
└── errors.jsonl         ما تعثّر
```

**ملفّ الصفقة الواحدة** يحمل ما طلبتَه: التاريخ، الأطر، الاتجاه،
الشمعة، السبريد، **وكل شرط ✅/❌ بدليله ومصدر درسه**، وموضعًا فارغًا
تكتب فيه ما حدث وحكمك على الشكل.

📝 **واملأ ذلك الموضع** حين تراجع. حكمُك على الشكل هو الطبقة الوحيدة
التي لا يوفّرها الكود.

## ماذا سأفعل بها

~24 معاملًا في البوت **غير معرَّف** — لم يعطِ المدرّب رقمًا: كم
سماحية؟ كم شمعة؟ كم قربًا؟

وأنفع ما في الحصاد **الفحوص الراسبة معدودةً**:

```
⭐ الفحوص الراسبة — هنا تُضبط العتبات:
    41  القرب من منطقة مفتاحية
    18  الموقع تحت بوابة الـ50%
```

«رسب فحص القرب 41 مرة» يضبط معاملًا. «لم يجد إعدادات» لا يضبط شيئًا.

## إن تعطّل شيء

| الرسالة | الحل |
|---|---|
| `'python' is not recognized` | لم تُوضع علامة PATH — أعد التثبيت |
| `لا يوجد config.local.py` | الخطوة ٥ |
| `ينقص config.local.py: MT5_PATH` | مسار `terminal64.exe` فارغ |
| `الرمز غير موجود في Market Watch` | راجع اسم الرمز — الخطوة ٤ |
| `تعذّر فتح الطرفية` | MT5 مغلق، أو المسار خطأ |
| `No module named MetaTrader5` | الخطوة ٣ |

وإن ظهر غير ذلك: افتح `runs\errors.jsonl` وأرسل لي آخر سطر.
