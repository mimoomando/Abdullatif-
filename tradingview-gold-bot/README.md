# tradingview-gold-bot

مشروع مستقل تماماً عن بوت الذهب القديم في هذا المستودع.

الهدف: استقبال إشارات مؤشر `RICH SCANNER PRO` من TradingView وتنفيذها
آلياً على حساب وسيط عبر API.

## الحالة: قيد التصميم — لم يُكتب كود التنفيذ بعد

## الطريق المقترح

```
مؤشر RICH SCANNER PRO على شارت الذهب
      ↓  تنبيه (Alert) يحمل ENTRY / SL / TP1 / TP2 / TP3
خادم يستقبل الإشارة ويتحقق منها
      ↓  أمر عبر API
حساب الوسيط ← هنا تُفتح الصفقة فعلياً
```

## ما تأكّد حتى الآن

- المؤشر يعرض خمس قيم في سطر الشارت: الدخول والوقف وثلاثة أهداف،
  وظهورها هناك يعني أنها قيم حقيقية يمكن سحبها داخل رسالة التنبيه.
- اتجاه الصفقة يُستنتج من موضع الوقف: تحت الدخول شراء، وفوقه بيع.
  أضمن من الاعتماد على كلمة مكتوبة في الرسالة.
- مصدر سعر الشارت OANDA، فحساب OANDA يعطي نفس الأسعار بلا فرق.
- حساب Paper Trading في TradingView لا يصلح للتنفيذ: لا API له.

## ما ينتظر التحقق

- هل يقبل المؤشر إنشاء تنبيه عليه أصلاً (قائمة Condition).
- خاصية Webhook تحتاج اشتراكاً مدفوعاً في TradingView؛ الحساب الحالي مجاني.
- اختيار الوسيط الذي سينفّذ الأوامر.
