# محرك تحليل «استراتيجية الذكاء»

يقرأ شموع `XAUUSD.m`، ويطبّق دروس المدرّب حسابيًا، **ويقترح** صفقة.

## ⛔ لا ينفّذ

```python
>>> from bot.guards import send_order
>>> send_order("XAUUSD.m", "buy", 0.01)
ExecutionBlocked: مرفوض: send_order()
التنفيذ غير مأذون. المأذون حاليًا: التحليل والاقتراح فقط.
```

المنع في الكود لا في التوثيق. لرفعه يلزم: اكتمال الدروس + إغلاق معاملات
`UNDEFINED` + إذن صريح جديد.

## لماذا لا يفتح TradingView؟

الشارت صورة للأرقام، والأرقام موجودة في MT5 مباشرة. قراءة الفيد نفسه الذي
ستنفّذ عليه **تتفادى التعارض C4** — اختلاف الذيول بين المزوّدين الذي لاحظه
المدرّب نفسه بين Capital.com و OANDA.

الرسم يبقى **مخرَجًا** للعرض، لا مصدرًا للتحليل.

## ما هو مبني ✅

| المفهوم | التعريف المنفَّذ |
|---------|------------------|
| القمة/القاع | أعلى من المجاورة مباشرة يمينًا ويسارًا (الدرس 9) |
| الاتجاه | قمم أعلى وقيعان أعلى ⇒ صاعد |
| كسر الهيكل | **بالجسم لا بالذيل** (الدرس 10) · BOS مقابل CHoCH |
| القمة الحقيقية | لا تُعتمد إلا إذا كسرت الحركة التالية القاع الحاكم (م2/د4) |
| الفراغ السعري | ثلاث شموع **بالذيول** · صاعد: `low[3] > high[1]` (الدرس 5) |
| دمج الفراغات | منطقة مركّبة ومنتصفها كمرجع إعادة تسعير (§7) |
| كسح السيولة | اختراق **ثم استعادة الإغلاق** — الكسر النظيف ليس كسحًا |
| فيبوناتشي | `القمة − (القمة−القاع) × النسبة` · 50 · 61.8 · 78.6 (الدرس 6) |
| بوابة القيمة | فوق الـ50% غالٍ للشراء — تقدير مخاطرة لا منع (الدرس 14 · §9) |
| الارتكاز | `(H+L+C)÷3` — مُتحقَّق مقابل أرقام المصدر (م2/د4) |
| الترند لاين | خط بين نقطتين · الإرساء معامل صريح بسبب التعارض C1 |
| القناة المتوازية | الخط نفسه مزاحًا · المنتصف سياق لا دخول |
| **الأوردر بلوك** | الثلاثية: كسح + كسر بالجسم + فراغ (د10 · م2/د3) |
| منطقته | المدى الكامل بالذيل — لا الجسم (م2/د4) |
| وقفه | أدنى المنطقة − السبريد الحي (م2/د3) |
| حالاته | fresh · mitigated · failed · breaker (د11 · §7) |
| الدخول من اللمس | بشرط سند فراغ إطار أعلى + تحت بوابة الـ50% |
| **السيولة الداخلية** | فراغ + أوردر بلوك — موضع دخول **لا هدف** |
| **السيولة الخارجية** | القمم والقيعان — هي الهدف |
| قوية مقابل مخففة | قمة منفردة ⇒ قوية · ومعها قمة قريبة ⇒ مخففة |
| السيولة المحمية | نظّفت ما قبلها **وارتدت من أوردر بلوك** ⇒ ليست هدفًا |
| الدورة | داخلية ثم خارجية ⇒ استمرار · بلا خارجية ⇒ احتمال تغيّر هيكل |
| بوابة الهيكل | الفراغات مع اتجاه الهيكل فقط — «ما بيتخيّط» |
| **الأنماط الانعكاسية** | دبل · ثلاثي · رأس وكتفين — **الشكل وحده لا يكفي** |
| التفعيل | كسر خط العنق **بالجسم** + فراغ عند الكسر (§10) |
| الإبطال | كسر طرف النموذج قبل التفعيل |
| الدخول | من **إعادة اختبار فراغ الكسر** لا من الكسر نفسه |

## ما لم يُبنَ بعد ⏳

أنماط الاستمرار (Flag · Pennant) · الرسم · تيليجرام · جسر MT5

## سلسلة القرار

```
١. الهيكل على إطار نقطة الاهتمام
٢. نقطة اهتمام مع اتجاه الهيكل
٣. وصول السعر إليها
٤. الموقع تحت بوابة الـ50%
٥. النزول إلى الإطار المقابل من جدول الأزواج
٦. دخول من اللمس (بشرط التسلسل)  أو  نموذج انعكاسي مفعَّل
٧. هدف على السيولة الخارجية — بحد 1:3
٨. بوابة المخاطرة — حد المراكز
```

تتوقف عند **أول فشل** وتسجّله. المخرَج `TradeRationale` جاهزة للعرض
في تيليجرام وللسجل اليومي.

## لماذا لا يحتاج البوت «أدوات» المنصة؟

| الأداة في المنصة | ما هي فعلًا |
|---|---|
| فيبوناتشي | `القمة − (القمة−القاع) × النسبة` |
| ترند لاين | خط بين نقطتين: `y = ميل·س + مقطع` |
| قناة متوازية | الخط نفسه مزاحًا بمقدار ثابت |
| مستطيل (منطقة FVG) | سعران: أعلى وأدنى |
| خط أفقي (دعم) | سعر واحد |
| ارتكاز | `(H+L+C) ÷ 3` |

أداة الرسم مسطرة **لعين الإنسان**. البوت يحسب الرقم ولا يحتاج أن يراه مرسومًا.
`python3 -m bot.demo_tools` يطبع الحساب خطوة بخطوة.

## قواعد التطوير

1. **لا قاعدة بلا مصدر.** كل معامل يذكر درسه أو يُوسم `UNDEFINED`.
2. **لا تخمين للفراغات.** ما لم يعرّفه المدرّب يبقى مقبضًا مكشوفًا لا رقمًا مخفيًا.
3. **لا كود تنفيذ.** حتى إذن صريح.
