# محرك تحليل «استراتيجية الذكاء»

يقرأ شموع `XAUUSD.m`، ويطبّق دروس المدرّب حسابيًا، **ويقترح** صفقة.

## ⛔ لا ينفّذ

```python
>>> from bot.guards import send_order
>>> send_order("XAUUSD.m", "buy", 0.01)
ExecutionBlocked: مرفوض: send_order()
التنفيذ غير مأذون. المأذون حاليًا: التحليل والاقتراح فقط.
```

المنع في الكود لا في التوثيق. لرفعه يلزم: اكتمال الدروس + إغلاق معاملات
`UNDEFINED` + إذن صريح جديد.

## لماذا لا يفتح TradingView؟

الشارت صورة للأرقام، والأرقام موجودة في MT5 مباشرة. قراءة الفيد نفسه الذي
ستنفّذ عليه **تتفادى التعارض C4** — اختلاف الذيول بين المزوّدين الذي لاحظه
المدرّب نفسه بين Capital.com و OANDA.

الرسم يبقى **مخرَجًا** للعرض، لا مصدرًا للتحليل.

## صور الشارت

`write_charts()` يكتب **صورتين لكل إعداد**، ولكلٍّ غرض — والخلط بينهما
يفسد القياس:

| الصورة | ما عليها | لماذا |
|---|---|---|
| `annotated` | الشموع + مناطق البوت + دخول/وقف/هدف | **للدراسة**: ترى أين رسم البوت مناطقه، فإن أخطأ الموضع عرفته بعينك |
| `plain` | الشموع عارية | **للحكم**: ما إن يُرسم فوقها استنتاج البوت حتى يصير الناظر يقيّم استنتاجه لا شكل السوق |

⚠️ **الصورة المرسومة ليست مصدرًا مستقلًا.** هي الأرقام نفسها بلبوس آخر،
فلا تضيف شيئًا لحكم يُبنى على تلك الأرقام. الصورة المستقلة الوحيدة هي
لقطة من طرفية MT5 (`ChartScreenShot()`) — بكسل من عند الوسيط لا من عند
البوت، وتنتظر جسر MT5.

**التسميات على الشارت لاتينية** (`Entry` · `SL` · `TP1` · `OB` · `FVG`)
لأن محوّلات SVG→PNG لا تصل الحروف العربية ولا تعكس اتجاهها فتخرج «شراء»
مقلوبةً «ءارش». والشرح العربي في نصّ السجل حيث يُعرض صحيحًا. اختبار يمنع
تسرّب حرف عربي إلى الشارت.

SVG بمكتبة قياسية فقط. التحويل إلى PNG اختياري (`cairosvg`) — تيليجرام
يعرض PNG داخل المحادثة ويرسل SVG مرفقًا.

## قرار «أبقِها مفتوحة» — وكيف يُراجَع

المدرّب ينصح بعدم تنييم الصفقة (وايكوف/د3):

> «ما تنيّم صفقة حتى لو متأكد إنه السوق طالع — **ما بتعرف على شو بيفتح السوق**»

المستخدم اختار خلافه (2026-08-27) — **مخالفة واعية ومؤقّتة على حساب
تجريبي**، شرطها أن تُقاس لا أن تُنسى:

```
SessionGap        آخر سعر قبل الإغلاق ↔ أول سعر بعد الافتتاح
journal.slept     هل نامت؟
journal.gap_effect  صافي ما فعلته الفجوات لصالح اتجاه الصفقة
```

الفجوة تدخل في MFE/MAE — فهي حركة سعر حقيقية وقعت على المركز ولا يصحّ
إخفاؤها. والسجل اليومي يرفع البند إلى `high` إن تضرّرت صفقة، وإلى `low`
إن لم تتضرّر. بعد أسابيع يُراجَع القرار **برقم لا بجدل**.

## سلسلة القرار

```
١. الهيكل على إطار نقطة الاهتمام
٢. نقطة اهتمام مع اتجاه الهيكل
٣. وصول السعر إليها
٤. الموقع تحت بوابة الـ50%
٥. النزول إلى الإطار المقابل من جدول الأزواج
٦. دخول من اللمس (بشرط التسلسل)  أو  نموذج انعكاسي مفعَّل
٧. هدف على السيولة الخارجية — بحد 1:3
٨. بوابة المخاطرة — حد المراكز
```

تتوقف عند **أول فشل** وتسجّله. المخرَج `TradeRationale` جاهزة للعرض
في تيليجرام وللسجل اليومي.

## اعتراض المدرّب وكيف يُقاس

قال المدرّب (2026-08-27):

> «لو **الشكل صح بس الحساب غلط** — بيرفض.
>  وإذا **الحساب صح بس الشكل غير مطابق** — بفوت»

الاعتراض صحيح ويسمّي نوعَي خطأ حقيقيين. الردّ عليه **قياس لا جدل**:

| نوع الخطأ | كيف يُقاس | أين |
|---|---|---|
| شكل صح · حساب غلط ⇒ رفض | كل نموذج يُسجَّل **حتى غير المفعَّل** · و«الرفض بفارق ضئيل» يُعدّ | `observer.py` |
| حساب صح · شكل غلط ⇒ دخول | **لا يراه الكود** — يحتاج عينًا خارجه | `verdicts.py` |

المراقب **يصف ولا يقرّر**: لا يحمل دخولًا ولا وقفًا، واختبار يثبت ذلك.

### حلقة الحكم اليومية

السجل يُذيَّل بسؤال واحد — **هل كان الشكل مطابقًا؟** — والردّ سطر لكل إعداد:

```
١ نعم
٢ لا الشكل ما كان مطابق
```

### من يحكم؟ وطريقان لا واحد

| الحاكم | ماذا يرى | مستقل؟ |
|---|---|---|
| المستخدم | الشارت بعينه | ✅ دائمًا |
| المساعد + **حزمة الحكم** | الشموع الخام | ✅ مراجعة فعلية |
| المساعد + السجل وحده | خلاصات البوت | ❌ تصديق لا مراجعة |

السطر الأخير هو المصيدة: لو حكم المساعد من «رُفض لأن الفارق 3 والسماحية 1.5»
فهو **يعيد حساب البوت** ويوافقه بحكم البناء — فترتفع «الدقة» بلا أن يُقاس شيء.

لذلك `judging_packet()` يحمل **الشموع الخام** ويحجب عمدًا:

```
سبب الرفض · قيمة العتبة · «رُفض بفارق ضئيل» · النتيجة (R)
```

والنتيجة محجوبة تحديدًا لأن الرابحة قد يكون شكلها خاطئًا، والخاسرة سليمًا.

`Accuracy` يحسب النسب على **الأحكام المستقلة وحدها**، ويعلن كم استبعد ولماذا.
وإن لم يكن فيها مستقل واحد، يمتنع عن عرض النسب أصلًا.

`DailyReport.apply_verdicts()` يلصق الردّ بالإعدادات حسب الترقيم المعروض،
و`Accuracy` يتراكم عبر الأيام فيعطي رقمين:

```
❌ إيجابية كاذبة (تصرّف والشكل خاطئ)  ⇒ الشروط فضفاضة
⛔ سلبية كاذبة  (رفض والشكل صحيح)     ⇒ الشروط ضيقة
```

ويربط السلبيات الكاذبة بـ«الرفض بفارق ضئيل» الذي رصده المراقب: إن تطابقا،
فالمشكلة معايرة عتبة لا منهج.

⚠️ **الحكم لا يغيّر سلوك البوت تلقائيًا**، والتقرير يرفض المعايرة تحت
عيّنة 20 حكمًا. بعد أسابيع يكون لدينا ردّ بالأرقام.

## قواعد التطوير

3. **لا كود تنفيذ.** حتى إذن صريح.

خطة المستخدم (2026-09-05): «نشغّل البوت على وضعه، ونجعل له سجلًّا
للصفقات وسجلًّا للشارت، وبعد أسبوع أرسل لك السجل وأنت تستنتج الأجوبة
**من الواقع لا تخمينًا**».

```bash
python -m bot.runner --watch --every 60     # على ويندوز، اتركه يعمل
python -m bot.runner --package              # بعد أسبوع
```

يُنتج تحت `runs/`:

| | |
|---|---|
| `decisions.jsonl` | قرار لكل شمعة مغلقة، **بسلسلة الفحص كاملة** |
| `charts/*.svg` | الشموع **عارية** — بلا رسم البوت فوقها |
| `errors.jsonl` | ما تعثّر، بمكانه — لا يوقف الحلقة |

⭐ **الفحوص الراسبة هي الحصاد الحقيقي.** «رسب فحص القرب 41 مرة» يجيب
على معامل معلّق؛ «لم يجد إعدادات» لا يجيب على شيء.

⛔ **لا أوامر.** الجسر يقرأ، و`guards.EXECUTION_ENABLED = False`،
والحلقة نفسها خالية من أي دالة تنفيذ — يثبته اختبار يمسح المصدر.
