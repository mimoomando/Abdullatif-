# محرك تحليل «استراتيجية الذكاء»

يقرأ شموع `XAUUSD.m`، ويطبّق دروس المدرّب حسابيًا، **ويقترح** صفقة.

## ⛔ لا ينفّذ

```python
>>> from bot.guards import send_order
>>> send_order("XAUUSD.m", "buy", 0.01)
ExecutionBlocked: مرفوض: send_order()
التنفيذ غير مأذون. المأذون حاليًا: التحليل والاقتراح فقط.
```

المنع في الكود لا في التوثيق. لرفعه يلزم: اكتمال الدروس + إغلاق معاملات
`UNDEFINED` + إذن صريح جديد.

## لماذا لا يفتح TradingView؟

الشارت صورة للأرقام، والأرقام موجودة في MT5 مباشرة. قراءة الفيد نفسه الذي
ستنفّذ عليه **تتفادى التعارض C4** — اختلاف الذيول بين المزوّدين الذي لاحظه
المدرّب نفسه بين Capital.com و OANDA.

الرسم يبقى **مخرَجًا** للعرض، لا مصدرًا للتحليل.

## التشغيل

```bash
python3 -m unittest discover -s bot/tests -t .   # 21 اختبارًا

```

## حالة المعاملات

| النوع | العدد | المعنى |
|-------|-------|---------|
| `SOURCE` | **17** | منصوص عليه في درس |
| `UNDEFINED` | **10** | §17 — قيمة أولية تُضبط بالاختبار التاريخي |

`python3 -m bot.params` يطبع القائمة العشرة كاملة مع مرجع كل واحد.

## ما هو مبني ✅

| المفهوم | التعريف المنفَّذ |
|---------|------------------|
| القمة/القاع | أعلى من المجاورة مباشرة يمينًا ويسارًا (الدرس 9) |
| الاتجاه | قمم أعلى وقيعان أعلى ⇒ صاعد |
| كسر الهيكل | **بالجسم لا بالذيل** (الدرس 10) · BOS مقابل CHoCH |
| القمة الحقيقية | لا تُعتمد إلا إذا كسرت الحركة التالية القاع الحاكم (م2/د4) |
| الفراغ السعري | ثلاث شموع **بالذيول** · صاعد: `low[3] > high[1]` (الدرس 5) |
| دمج الفراغات | منطقة مركّبة ومنتصفها كمرجع إعادة تسعير (§7) |
| كسح السيولة | اختراق **ثم استعادة الإغلاق** — الكسر النظيف ليس كسحًا |

## ما لم يُبنَ بعد ⏳

Order Block (الثلاثية: كسح + كسر + FVG) · الترند لاين والقنوات ·
فيبوناتشي وبوابة 50% · الأنماط الانعكاسية والاستمرارية · Pivot ·
سلسلة القرار متعددة الأطر · توليد الصفقة المقترحة · الرسم · تيليجرام

## قواعد التطوير

1. **لا قاعدة بلا مصدر.** كل معامل يذكر درسه أو يُوسم `UNDEFINED`.
2. **لا تخمين للفراغات.** ما لم يعرّفه المدرّب يبقى مقبضًا مكشوفًا لا رقمًا مخفيًا.
3. **لا كود تنفيذ.** حتى إذن صريح.
